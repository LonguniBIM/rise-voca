# Source and illustration notices

The application uses native Unicode emoji rendered by the user's installed system fonts, and original CSS drawings. No emoji font files, external icon packs, third-party image bytes or remote illustration URLs are included. Native glyph artwork varies with device/platform. The original geometric app icons are generated without a font dependency.

The parent supplied lesson targets and the original seven-question quiz. The source school scans, corporate logo and complete stories are not redistributed. This repository's app/content authorization does not independently establish rights to publish further school materials. Review redistribution rights before adding scans, books, recordings or images.

No external artwork has been attached for customer, white oak or milkweed. Unresolved vocabulary meanings are also left without fabricated illustrations. Forty original Unicode/CSS candidates require device-local parent review. Parent decisions, histories and voice choices must never be committed to this public repository.

Development-only browser tests use Microsoft Playwright (Apache-2.0) installed from PyPI by CI. GitHub workflow actions retain their upstream licenses. These development tools are not runtime CDN dependencies.
